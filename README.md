# Metaohjelmoinnin esimerkkikoodit

Tämä repositorio sisältää lyhyitä ja ytimekkäitä koodiesimerkkejä metaohjelmoinnista eri ohjelmointikielillä. Esimerkit havainnollistavat, miten metaohjelmointia voidaan hyödyntää käytännössä muun muassa koodin generointiin, käyttäytymisen muokkaukseen ja ohjelman rakenteen manipulointiin ajon tai käännön aikana.

---

## Sisältö

- `python/`

  - Esimerkkejä **dekoraattorien** ja **metaluokkien** käytöstä metaohjelmoinnissa.

- `clojure/`

  - Esimerkki **threading macro** -rakenteesta, joka parantaa koodin luettavuutta.

- `c++/`
  - Esimerkki **mallipohjaisesta metaohjelmoinnista (template metaprogramming, TMP)** C++-kielellä.
